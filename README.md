# SliceToSheet

Программа читает STL, STEP и STP, режет объём на слои заданной толщины и детали, помещающиеся в A4, размещает отверстия под деревянные шпильки и сохраняет STL, SVG и карту сборки.

## Скачать и запустить — Windows x64

Скачайте **SliceToSheet-1.0.0-Windows-x64.zip** на странице [Releases](https://github.com/AegonnI/SliceToSheet/releases/latest), полностью распакуйте архив и запустите **SliceToSheet.exe**. Python, установка библиотек и подключение к интернету для работы не нужны. Папка `_internal` должна оставаться рядом с `.exe`.

Выберите модель, проверьте ось, размеры, толщину слоя и параметры отверстий, затем выберите папку результатов и нажмите «Нарезать и экспортировать». Результаты по умолчанию сохраняются в `STL_A4_Results` в домашней папке пользователя. Для передачи другому человеку отправляйте весь ZIP.

## Запуск из исходников и сборка

Для исходников нужен Python 3.9 или 3.10 x64 с Tk. Из папки проекта:

```powershell
py -3.10 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

Для создания переносимой Windows-версии запустите `BUILD_WINDOWS.bat`. Он установит зависимости сборки, соберёт папку, проверит упакованное приложение и создаст ZIP с SHA-256 в `releases/`. Распакованная сборка находится в `dist/SliceToSheet/`. Сборка выполняется на Windows; интернет нужен только для установки зависимостей.

Диагностика готовой сборки:

```powershell
Start-Process .\SliceToSheet.exe -ArgumentList '--check-installation', 'diagnostics.json' -Wait
```

В `diagnostics.json` сохраняется результат проверки окна, 3D-предпросмотра, импорта STL/STEP, нарезки, экспорта и продолжения расчёта. Успех — `"ok": true`.

## Запуск и настройки

### Свободное пространство вокруг SVG

Настройка «Свободное пространство SVG, мм» добавляет отступ с каждой стороны документа (по умолчанию 2 мм, диапазон 0–100 мм). Контуры, подписи и линии указателей смещаются вместе без масштабирования. Размеры модели, STL, отверстия и сетка нарезки не меняются. SVG задаёт физические размеры в миллиметрах; одна единица координат соответствует одному миллиметру.

При отступе 2 мм документ портретной ориентации имеет размер 214 × 301 мм вместо 210 × 297 мм; горизонтальной — 301 × 214 мм. Печатайте в режиме «100%» / «Фактический размер». «Вписать в страницу» может уменьшить чертёж. Для детали полного A4 с отступом нужен больший лист. Если используется A4, настройка «Поля A4, мм» уменьшает размер ячеек нарезки, сохраняя масштаб всей модели; проверьте доступную область печати принтера.

В командной строке: `--svg-padding 2`. Значение сохраняется с настройками нового расчёта. Старые настройки и продолжение старых расчётов используют отступ 0 мм для сохранения прежней раскладки; для другого отступа начните новый расчёт. Уже созданные SVG автоматически не перезаписываются.

Для обновления переносимой версии распакуйте новый ZIP в отдельную папку. Папки моделей и результатов храните отдельно. Исходный файл модели и полную папку расчёта сохраняйте для продолжения работы.

## Тестовый режим четырёх отверстий — 28.09.2026

В основном окне по умолчанию включены перевязка швов и «4 отверстия: 2 вниз + 2 вверх (тест)». Уникальные тройки выключены: одновременно эти два режима использовать нельзя. Боковые шпильки внутри слоя выключены отдельной настройкой. Если включить их, они добавляются сверх четырёх межслойных отверстий.

В новом режиме на деталь выделяется не более двух соединений с нижним слоем и двух с верхним. Сначала программа ищет по одному отверстию для разных соседей, затем заполняет оставшиеся места вторым соединением с тем же соседом, если это возможно. Верхние и нижние каналы не пересекаются. Значение «Шпилек на стык» используется только для старого режима и боковых соединений.

Ровно четыре отверстия возможны не всегда: у первого и последнего слоя нет одного из соседних слоёв; на краях, тонких участках и при разном количестве деталей в соседних слоях может не хватить материала или доступных соединений. Фиктивные отверстия без ответной детали не добавляются. Недобор и несвязанные группы перечисляются в REPORT.txt. Это тестовый алгоритм с ограниченным поиском, не гарантия связности любой модели.

На SVG внутри контура печатается адрес, например `L2.R3.C4.1`: слой 2, строка 3, столбец 4, отдельный компонент 1 в этой ячейке. Нумерация начинается с 1; строки и столбцы относятся к сетке своего слоя с учётом перевязки. Возле отверстия: `DOWN L1.R3.C4.1 K0007` — соединение вниз, адрес ответной детали, общий номер шпильки. `UP` означает вверх, `SIDE` — внутри слоя. На обеих ответных деталях одинаковый номер K. Полная карта адресов и соединений также записывается в assembly.json.

Подписи размещаются в материале среднего сечения, вне отверстий. Если безопасного места для читаемой подписи нет, это отмечается в отчёте. Маркировка предназначена для печати SVG, в STL текст не выгравирован. SVG остаётся средним сечением объёмной детали, печатать в масштабе 100%.

Старые сохранённые настройки и расчёты сохраняют прежний алгоритм отверстий и боковые соединения. Для нового алгоритма начните новый расчёт и проверьте соответствующие флажки после загрузки старых настроек.

Файл STL, STEP или STP выбирается вручную. Настройки универсальные и не зависят от имени модели. Начальные значения: длина вдоль выбранной оси 8000 мм, исходная ось X, обратное направление, слой 20 мм, поля A4 0, шпилька 8 × 40 мм. Это только начальные значения; их можно изменить.

«Сохранить настройки» и «Загрузить настройки» работают с JSON. Файл содержит параметры, без привязки к STL и папке компьютера. Копия настроек также сохраняется в каждом расчёте как settings.json.

При ненулевой «Длине вдоль оси» программа рассчитывает единый масштаб и сохраняет пропорции. Поле «Масштаб модели» тогда не используется. Чтобы применять коэффициент вручную, задайте длину 0. STL не хранит единицы измерения; все размеры программы — миллиметры.

Слои перпендикулярны выбранной исходной оси. Без флажка направление идёт от минимума оси к максимуму, с флажком — обратно. В предпросмотре эта ось поворачивается в экранную Z. Программа не определяет автоматически нос, корму или другие части модели.

При полях 0 каждая деталь помещается в 210 × 297 мм (или 297 × 210 при горизонтальном A4). Это ограничение габаритов, а не только площади. При полях 5 мм доступно 200 × 287 мм. Последний слой может быть тоньше заданной толщины.

## Импорт STEP / STP

Поддерживаются расширения .step и .stp без учёта регистра, в окне программы и командной строке. Для импорта используется cadquery-ocp 7.7.2, включённый в Windows-релиз. При запуске из исходников установите зависимости из requirements.txt. STL загружается без загрузки CAD-библиотеки.

Единицы STEP преобразуются в миллиметры, затем применяются масштаб или заданная длина и выбранная ось. Все тела импортируются с сохранением расположения. Нужна замкнутая объёмная модель: открытые поверхности не подходят для нарезки.

Криволинейные поверхности STEP приближаются треугольниками: линейное отклонение 0,05 мм и угловой параметр 0,1 рад в исходном размере, до пользовательского масштабирования. При увеличении модели отклонение также увеличивается. Результаты по-прежнему сохраняются в STL, SVG и карте сборки.

Пример:

    .venv\Scripts\python.exe slicer.py model.step results --axis X --target-length 8000

## Пауза и продолжение

Новый расчёт создаёт отдельную папку sliced_... в выбранной папке результатов. Её путь выводится в журнале.

1. Нажмите «Приостановить расчёт». Остановка произойдёт после текущей геометрической операции; тяжёлая операция может не прерваться мгновенно.
2. Для продолжения нажмите «Продолжить сохранённый расчёт» и выберите эту папку — именно ту, где лежит progress.sqlite.
3. Программа восстановит параметры и сохранённые этапы. Если исходный файл модели перемещён, она попросит выбрать его заново и проверит содержимое по SHA-256.

Геометрия и прогресс сохраняются пакетами по 10 слоёв (интервал можно изменить), а также в конце этапа. Пауза и штатное закрытие окна сохраняют остаток полностью рассчитанных слоёв; незавершённый слой пересчитывается. При аварии восстанавливается последний сохранённый пакет, поэтому до 10 слоёв может потребоваться рассчитать повторно. Экспорт продолжается с неподготовленных файлов. Формирование общей assembly.stl при прерывании начинается заново, отдельные STL сохраняются.

Для переноса расчёта на другой компьютер копируйте всю папку результата и исходный файл модели. Не удаляйте progress.sqlite. Не запускайте два экземпляра для одной папки расчёта. При закрытии окна приложение сначала запрашивает паузу и ждёт завершения текущей операции.

Продолжение работает только для расчётов этой версии. Старый незавершённый запуск, который ничего не сохранял, перенести или восстановить нельзя.

## Память и скорость

Нарезка идёт блоками по 16 слоёв. Перед сохранением готовая геометрия накапливается в памяти пакетами по заданному интервалу. При расчёте отверстий нужен также следующий соседний слой: при интервале 10 в буфере может находиться до 11 слоёв плюс рабочие копии текущей пары. Это уменьшает повторную запись геометрии, но увеличивает использование ОЗУ. Для очень тяжёлых моделей можно уменьшить интервал. Конечные STL и SVG всё равно записываются по одному файлу на деталь.

Операции с отверстиями используют готовые шаблоны и сохранённые объёмные представления деталей. Проверки пересечений учитывают только ещё актуальные соединения. Программа не упрощает исходную геометрию ради ускорения; упрощение используется только в предпросмотре.

Показан отдельный прогресс нарезки, отверстий, экспорта и формирования общей сборки. Длительность каждого слоя записывается в журнал. Процент одного этапа не является процентом времени всей работы.

После завершения можно просмотреть отдельный слой по номеру. Вся многотысячная сборка не загружается автоматически в память окна.

## Результаты

- stl/ — отдельные детали в локальных координатах.
- sections_a4/ — SVG средних сечений, печать 100%. Это не проекция всей объёмной детали.
- assembly.stl — детали в общем расположении.
- assembly.json — параметры, размеры, номера слоёв, смещения деталей и соединения.
- connections.csv — координаты отверстий в общей системе. Для локальных вычтите assembly_offset детали.
- REPORT.txt — сводка, недостающие соединения и несвязанные группы.
- progress.sqlite — база для продолжения расчёта.
- settings.json — переносимые настройки.
- INCOMPLETE.txt — комплект ещё не готов для изготовления. После успешного завершения файл исчезает.

Шпилька 40 мм в двух слоях по 20 мм выходит заподлицо. На тонких участках подходящего места для неё может не быть: такие стыки отмечаются в отчёте. Программа проверяет геометрию, но не прочность, технологию изготовления и порядок сборки.

## Командная строка

Новый расчёт с исходной осью X, длиной 8000 мм, обратным направлением и полным A4:

    .venv\Scripts\python.exe slicer.py model.stl results --axis X --target-length 8000 --reverse --margin 0

Продолжение с сохранёнными параметрами:

    .venv\Scripts\python.exe slicer.py model.stl results --resume

## Перевязка швов и ключи — обновление 17.09.2026

Это описание прежнего режима троек, который можно включить вручную. При включении троек новый режим четырёх отверстий отключается, количество шпилек на стык устанавливается равным трём. Для изменения перевязки нужен новый расчёт.

Перевязка сдвигает сетку каждого второго слоя на половину размера детали по обеим осям в плоскости листа. Крайние детали могут быть меньше A4. Межслойные соседи ищутся по перекрытию, поэтому одна верхняя деталь может соединяться с несколькими нижними. Перевязка не гарантирует соединений там, где перекрытие слишком узкое для шпилек.

Ключ — три круглых отверстия прежнего диаметра, расположенные в вершинах несимметричного треугольника. Требуется ровно три шпильки на стык. Позиции воспроизводимы при повторном запуске и продолжении. Проверяются материал вокруг каналов, длина, отсутствие пересечений и целостность деталей. Тройка вырезается целиком либо не вырезается вообще.

Программа сравнивает три отсортированных межцентровых расстояния каждого ключа со всеми ранее принятыми ключами, независимо от оси. В допуске сравнения учитывается удвоенный «Допуск положения ключа»: по умолчанию 2 × 0,5 = 1 мм. Совпадающие, почти совпадающие, симметричные и почти коллинеарные рисунки отклоняются. Реестр сохраняется вместе с завершённым слоем, поэтому после возобновления ключи не повторяются. Шаг обычного поиска используется в старом режиме; новый режим выбирает воспроизводимые непрерывные позиции и выполняет ограниченный поиск.

Если найденного безопасного уникального рисунка нет, стык остаётся без отверстий и помечается «КЛЮЧ НЕ СОЗДАН». Это означает неудачу ограниченного поиска, а не математическое доказательство невозможности разместить отверстия. Проверьте замечания и несвязанные группы перед изготовлением.

Граница проверки: сравниваются полные тройки каждого стыка. Произвольные сочетания отверстий от разных стыков, частичная посадка на одну/две шпильки, все положения целых деталей и доступность отверстий с противоположной стороны не проверяются. Сквозной канал остаётся доступен с обеих сторон. Поэтому этот режим различает полные рисунки ключей, но НЕ гарантирует единственный физически возможный вариант сборки всей модели. Граница проверки записывается в REPORT.txt и assembly.json/key_validation.

В connections.csv и assembly.json добавлены key_id (общий для трёх шпилек стыка) и key_signature (три расстояния в мм). Геометрия STL сохраняется объёмной. SVG по-прежнему показывает среднее сечение; это не автоматическое превращение объёмной детали в плоскую выкройку с точным наклонным наружным контуром.

При обновлении обязательно перенесите keys.py вместе с app.py, slicer.py и pipeline.py.

Командная строка: новый режим четырёх отверстий включён по умолчанию; `--staggered` включает перевязку, `--side-connections` — боковые шпильки, `--checkpoint-layers 10` задаёт интервал сохранения. `--legacy-holes` возвращает старый счётчик на стык, а `--unique-keys` включает прежние тройки вместо четырёх отверстий.
